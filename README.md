# AlfGAmeX Studio - Rasmiy Veb-Sayt (Ko'p Tilli & Yangilangan Versiya)

Mustaqil indie o'yin va ilovalar dasturchisi **Alfa** tomonidan asos solingan **AlfGAmeX Studio** rasmiy portfeli.

- **Studiya nomi:** AlfGAmeX Studio
- **Asos solingan sana:** 17-fevral, 2025-yil
- **Dasturchi:** Alfa (Mustaqil / Solo Indie Developer)
- **Tillar:** Inglizcha (EN - Asosiy / Default) va O'zbekcha (UZ).
- **UI Uslubi:** Jiddiy Qora Tungi (OLED / Cyber Studio) va Klassik Oq Kunduzgi rejimlari.
- **Logotip formulasi:**
  - `Alf`: To'q siyoh rang (Deep Violet / Neon Violet `#a855f7`)
  - `GAme`: Oq rang (`#ffffff`)
  - `X`: To'q siyoh rang (Deep Violet / Neon Violet `#a855f7`)
- **Rasmiy Emblema:** `assets/images/alfgamex-emblem.png` va brauzer sarlavha panelida `assets/images/favicon.png`.
- **Mobil Moslashuvchanlik:** Barcha zamonaviy smartfonlar, planshetlar va noutbuklarga 100% moslashtirilgan.

---

## 🌐 Ikki Tilli Tizim (English & O'zbekcha)

- Sayt birinchi ochilganda **Ingliz tilida (EN)** ochiladi.
- Tepadagi navbar orqali **`[ EN | UZ ]`** tugmasini bosib, saytning barcha qismlarini (bosh sahifa, biz haqimizda, o'yinlar ta'rifi, modallar, tamoyillar, aloqa va pastki qismlar) bir zumda to'liq o'zbek tiliga tarjima qilish mumkin.
- Tanlangan til brauzer xotirasida (`localStorage`) saqlanadi.
